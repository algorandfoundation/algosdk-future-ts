## Breaking Changes

- Rename the package from `@joe-p/algokit-lite-generator` to `@joe-p/algosdk-generator` as part of the rebrand from algoKIT lite to algosdk-future.
- Rename the `algokit-lite` CLI to `algosdk-future`.
- Generated clients import from `@joe-p/algosdk-app-client` and `@joe-p/algosdk-composer` by default.
